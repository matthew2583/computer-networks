# Сети - Лабораторные работы

Учебные сетевые топологии в двух симуляторах: Huawei eNSP и Cisco EVE-NG.

---

## Структура репозитория

```
├── eNSP(Huawei)/        # Топология в Huawei eNSP
│   └── final.topo       # Корпоративная сеть с VLAN и Wi-Fi
│
└── eve(Cisco)/          # Лабораторные работы в EVE-NG
    ├── BGP.unl          # BGP между 6 маршрутизаторами
    ├── Routing.unl      # Статическая/динамическая маршрутизация
    └── VLAN.unl         # Настройка VLAN и транков
```

---

## Лабораторные работы

### Huawei eNSP - Корпоративная сеть (`final.topo`)

Многоуровневая топология предприятия на базе коммутаторов **Huawei S5700**.

**Оборудование:** 4 коммутатора (S1–S3, S6), AC6005 (контроллер Wi-Fi), AP4050, сервер, 5 ПК

**VLAN:**
| VLAN | Назначение |
|------|------------|
| 10 | Server Farm (`192.168.0.x`) |
| 100 | Администрация (`192.168.100.x`) |
| 101 | Маркетинг (`192.168.101.x`) |
| 102 | R&D (`192.168.102.x`) |
| 200 | Корпоративный Wi-Fi |
| 201 | Гостевой Wi-Fi |

---

### Cisco EVE-NG - `BGP.unl`

6 маршрутизаторов (R1–R6) + клиентский роутер C1. Отработка BGP-сессий, анонсирование префиксов, политики маршрутизации.


---

### Cisco EVE-NG - `Routing.unl`

3 маршрутизатора + 2 коммутатора. Статическая и динамическая маршрутизация (OSPF).

---

### Cisco EVE-NG - `VLAN.unl`

3 коммутатора + 4 маршрутизатора. Настройка VLAN, транковых портов, Inter-VLAN маршрутизация.
