# Сети - Лабораторные работы

Лабы по сетям в Huawei eNSP и Cisco EVE-NG.

```
├── eNSP(Huawei)/
│   └── final.topo
│
└── eve(Cisco)/
    ├── BGP.unl
    ├── Routing.unl
    └── VLAN.unl
```

---

## eNSP - Корпоративная сеть

Настройка корпоративной сети с нуля. Коммутация (VLAN, LACP, RSTP), маршрутизация, DHCP, Wi-Fi через контроллер AC + точка доступа AP. Отдельные VLAN под серверы, отделы и Wi-Fi гостей. Разграничение доступа между сегментами через ACL, выход в интернет через NAPT.

---

## EVE-NG - VLAN.unl

Базовая работа с VLAN на Cisco. Настройка trunk-портов на коммутаторах, распределение устройств по VLAN, проверка изоляции - устройства в одном VLAN видят друг друга, в разных - нет.

---

## EVE-NG - Routing.unl

Маршрутизация и отказоустойчивость. VRRP между двумя маршрутизаторами, DHCP с relay, агрегация каналов LACP, spanning-tree с заданным root-коммутатором. Статические маршруты с разным приоритетом и проверка достижимости через loopback.

---

## EVE-NG - BGP.unl

BGP снаружи и внутри автономной системы. eBGP между тремя независимыми AS, iBGP внутри AS 65000 поверх OSPF (зоны 0 и totally stub). Управление путями через атрибуты BGP - лучший маршрут принудительно заворачивается через нужный канал.
